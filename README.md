# Startup Profit Analysis

## Project Overview
This project analyzes startup investments and predicts profits using Python, Machine Learning and Microsoft Power BI. It explores financial data to understand profit performance and spending patterns across different states.

## Project Objectives
- Analyze startup investment and profit data.
- Understand state-wise profit performance.
- Analyze marketing, R&D and administration expenses.
- Build a profit prediction model.
- Create an interactive Power BI dashboard.
- Present meaningful business insights.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Microsoft Power BI

## Dataset
- Dataset: StartupData.csv
- Contains startup financial and investment-related information.

## Dashboard Overview

- Total Profit: 5.60M

### State-wise Analysis
- New York
- Florida
- California

## Key Findings
- New York records the highest profit at 1.93M.
- Florida has the highest marketing spend at 4.0M.
- R&D spending is distributed relatively evenly.
- New York has the highest administration spend at 2.07M.
