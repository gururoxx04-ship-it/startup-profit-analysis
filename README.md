# Startup Profit Analysis

## Project Overview
This project analyzes startup investments and predicts profits using Python, Machine Learning and Power BI.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Microsoft Power BI

## Dataset
- Total Startups: 50
- R&D Spend
- Administration
- Marketing Spend
- Profit

## Machine Learning
Multiple Linear Regression

## Model Performance
- Mean Absolute Error: 6979.15
- R2 Score: 0.9001

## Project Files
- Power BI Dashboard
- Python Jupyter Notebook
- Startup Dataset
- Final Profit Analysis
- Profit Prediction Results
- Project Summary

## Conclusion
This project uses data analysis and machine learning to understand startup spending patterns and predict potential profits.
